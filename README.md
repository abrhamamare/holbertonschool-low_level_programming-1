# C Algorithms and Data Structures Exercises

C coursework spanning arrays, pointers, linked lists, stacks, sorting, binary trees, hash tables, and search algorithms.

## Technologies and topics

C, algorithms, data structures, memory management.

## Getting started

Compile individual exercises in their topic directories with GCC as required.

## Repository contents

This is an educational/practice repository. Browse the existing files and folders for the examples; individual exercises may have different requirements.

## Interview discussion

Compare time complexity, memory ownership, and algorithmic tradeoffs.

## Scope

Learning and practice work, not a production-ready or security-audited application.
